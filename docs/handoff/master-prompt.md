# Master prompt

Every packet in [tasks/](tasks/) belongs to the sibling apps plan, so one prompt starts a worker, Claude or ChatGPT, on
any of the three repos. It's uma-platform's
[`docs/handoff/master-prompt.md`](https://github.com/luismlorenzana/uma-platform/blob/main/docs/handoff/master-prompt.md)
(local: `~/workspace/uma-platform/docs/handoff/master-prompt.md`). Paste it, then name a packet, for example "Take SB5".

This file's earlier ChatGPT-only prompt is in git history: `git show 3ee16bf:docs/handoff/master-prompt.md`.
