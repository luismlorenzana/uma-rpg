Skill names

Approved 2026-11-04 (D298) and built (H167): one naming grammar for all 70 skill trees, in place of the Final Fantasy words, the five Spellblade prefixes and the hand-picked ladders. 528 of the 560 skills change name; there are 350 distinct names (mirrored classes share theirs). The design doc is skill-names.md.

The grammar

A tree has one word. Depths 2–4 put the same ladder before it in every tree, depth 5 is the tree's own capstone, and line B is line A's name with the line's word after it. The example is the Brawler's Greatsword, today's names struck through.
