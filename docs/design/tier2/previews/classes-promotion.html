Promotion and switching, Tiers 2 and 3

Round 3 (classes.md §4.10, §6.6): each Ascend is a promotion. Into Tier 2 she picks among every child of every Tier 1 class she brought to Class Rank 50; into Tier 3, among the Tier 3 children of every Tier 2 class at Rank 50. Every open class is hers at Class Rank 1, switched freely; a door at Class Rank 20 opens more. Progression owns the sheet's flow (T2W16, T2W31); this page mocks the class page.
