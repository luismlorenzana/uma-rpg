One GCP project, three apps that can't reach each other

Each app has its own site, API, database, images, runtime account, deployer and deploy sign-in. Only the Google login, the deploy pool, the budget and the read-only master data are shared. The farm's server takes parcel calls from the games' servers, each signed with Google's token for that server's own account.
