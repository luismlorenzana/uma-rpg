# S5 — Learning District

> **Status: built and deploying, 2026-10-10.** Design: game design §4–§6, [pacing.md](../../../design/pacing.md), D57.

## Goal

Umas train class proficiency and gear mastery while you're away. Class ranks now open skill depths (replacing S3's
level gates); mastery ranks will let them equip higher-grade gear (S7).

## What the owner sees

- **Five class halls** (Brawler Dojo, Mage Tower, Spell Blade Salle, Cleric Chapel, Summoner Circle) and **four
  armories** (Ranger's Lodge, Lancer's Barracks, Arcane Armory, Knight's Bastion) open on the Learning District page.
- A hall's slot trains one Uma one rank in its class; an armory's slot trains one of its gear types. The sheet shows
  each Uma's current rank, what the next rank does and how long it takes at her aptitude (running style for classes,
  distance for gear). **Rank up** when done; **Recall** cancels. Training can't be rushed. The Hub shows who's
  training, with Ready tags.
- **Skills**: a class at rank 1 learns no skills; each rank opens one depth (rank 6 opens the capstones). The skills
  page shows the build's class rank and where to train it.
- **Profile**: her five class ranks and any trained mastery.
- Umas who learned skills in S3 keep them: each class starts at the rank its learned skills need.

## Exit check

Historical check; releases use the [current phone script](../../../testing/phone-check.md).

Train a fresh Uma to Brawler rank 2 at the Brawler Dojo, learn a depth-1 skill, and start a mastery rank at an
armory; both show on the Hub while running.
