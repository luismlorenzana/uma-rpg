# Uma RPG

A personal, never-distributed party RPG inspired by *Umamusume: Pretty Derby* and Octopath Traveler, played on the
owner's iPhone as a Home Screen web app. It has its own Hub, passive farm, per-Uma leveling, chapter maps and turn-based
party battles.

## Status

Phase 1 has not started: a design spec, then the scaffold and the RPG rules ported from uma-racer. See the cross-game
[roadmap](https://github.com/luismlorenzana/uma-platform/blob/main/docs/roadmap.md).

## Where things are decided

- **Cross-game architecture** (master data, shared packages, stack, art): `uma-platform/docs/architecture.md`.
- **This game's design and decisions:** `docs/` in this repo (created in Phase 1).
